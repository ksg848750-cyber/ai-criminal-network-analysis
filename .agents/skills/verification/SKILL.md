# Verification Skill

Before declaring success:

- load sample data
- verify extraction
- verify entity resolution
- inspect Neo4j graph
- generate planted lead
- inspect reasons
- inspect evidence
- verify timeline
- verify review action
- verify SHA-256
- test false-similarity case

Report failures clearly.
