# MVP Implementation Skill

1. Read `PROJECT_CONTEXT.md`.

3. Read the relevant context file.
4. Identify the smallest working change.
5. Implement it.
6. Run tests.
7. Run the relevant demo path.
8. Report changes and limitations.

Do not implement future phases unless necessary for the current phase.
