# Criminal Network Intelligence MVP — Starter Pack

This repository is the **project onboarding pack** for building the SIH 26189 prototype with Google Antigravity.

The most important file is:

```text
PROJECT_CONTEXT.md
```

It explains the project from the product/problem level rather than assuming the coding agent already understands the idea.

## Quick start for the human developer

1. Extract the pack.
2. Open it as the Antigravity project/workspace.
3. Do not ask the agent to code immediately.
4. Paste `docs/ANTIGRAVITY_FIRST_PROMPT.md`.
5. Review the agent's understanding.
6. Correct any project decisions you want to change.
7. Approve Phase 1.
8. Build incrementally.

## Quick start for Antigravity

Read:

```text
PROJECT_CONTEXT.md
AGENTS.md
docs/PRD.md
docs/SYSTEM_DESIGN.md
docs/DATA_MODEL.md
docs/AI_LOGIC.md
docs/DEMO_SCENARIO.md
docs/UI_SPEC.md
docs/BUILD_PLAN.md
```

Then use the context-specific files under:

```text
context/
```

## Important

This is a hackathon MVP.

The goal is not to recreate a national police intelligence platform.

The goal is to produce one convincing, explainable end-to-end workflow:

```text
crime records
→ entities
→ resolved entities
→ graph
→ potential connection
→ evidence
→ investigator verification
```
