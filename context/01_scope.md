# PART 1 — SCOPE

The MVP is a local prototype of an investigator intelligence-analysis workflow.

## Must have

- synthetic data
- ingestion
- normalization
- entity extraction
- relationship extraction
- entity resolution
- Neo4j graph
- transparent lead scoring
- evidence
- dashboard
- verification
- SHA-256 audit/integrity

## Nice to have

- GDS algorithms
- richer NLP
- Plotly analytics
- Docker
- small blockchain/hash-chain demo

## Defer

- real-time feeds
- Kafka
- real police integrations
- social scraping
- production IAM
- cloud deployment
- GNN training
- microservices
