# PART 6 — DASHBOARD

Use React.

Core components:

```text
Dashboard
├── Header
├── Filters
├── CaseList
├── NetworkGraph
├── LeadList
├── LeadDetail
├── EvidencePanel
├── Timeline
└── ReviewControls
```

Cytoscape.js handles the graph.

Plotly handles timeline/chart views.

The main visual story should be:

Graph → Lead → Why → Evidence → Verify.
